# ProCrafted Homes — A Modern Construction & Design Platform

ProCrafted Homes is a multi-page, fully responsive web project showcasing premium construction, interior, and renovation services.
Designed and built using HTML, CSS, JavaScript, and deployed via Vercel, it demonstrates practical front-end development with performance optimizations and dynamic components.

## Features-:

### Multi-Page Responsive Layout:
Home, Services, Contractors, Projects, Tools, About, Contact
Mobile-friendly and optimized UI
Smooth reveal-based animations

### AI Chatbot (Hugging Face Integration):
Custom /api/ai endpoint
Free-tier model routing
Real-time chat UI
Useful for construction queries

### Optimized Projects Gallery:
Custom thumbnail system
Lazy loading for performance
Full-size lightbox view
Super-fast rendering

### Contractors Directory:
Search + filter by city
Dynamic rendering from JSON
Clean UI with instant results

### Tools (Calculator + Estimation):
Smart Construction Cost Estimator
Material breakdown
Real-time updates


## Performance Enhancements:
Lazy-loaded all images
Added async decoding for thumbnails
Introduced medium-resolution hero images
Removed heavy animations
Clean reveal-based scroll animation system
Lighthouse-friendly structure


## Tech Stack:
HTML5 / CSS3 / JavaScript (ES6)
Hugging Face Inference Router (AI)
GitHub + Vercel Deployment
Responsive UI • Modular Scripts
